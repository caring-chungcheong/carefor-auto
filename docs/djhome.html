02

방문요양이 주간보호와 다른 점

같은 홍보 폼을 쓰되, 아래 차이 때문에 강조점이 달라집니다.

✅ 방문요양의 강점(홍보 포인트)

  • 대전 전역 커버 — 송영 차량·회차 제약이 없어 5개구 어디든 요양보호사가 방문. 주보의 "도보·송영권" 한계가 없음
  • 진입 장벽 낮음 — 시설 정원에 안 묶여 수급자 1명부터 즉시 개시
  • 통합요양 묶음 — 방문요양 + 방문목욕을 한 기관에서 → 보호자 편의·수가 활용
  • 주보와 상호연계 — 케어링 둔산·서구 주간보호와 재가↔주보 송객 가능

⚠️ 방문요양의 난점(대비할 것)

  • 초경쟁 — 대전 방문요양 250곳+ (구당 50곳+). 차별화 없으면 묻힘
  • 인력이 곧 매출 — 요양보호사 수·가동률이 매출 상한. 모집이 최우선 과제
  • 수급자 산재 — 한곳에 모이지 않고 가정에 흩어져 있어 유입 채널(B2B)이 핵심
  • 낮은 전환비용 — 수급자가 센터를 바꾸기 쉬움 → 요양보호사 만족·매칭 품질로 방어

04

대전 전역 커버리지

방문요양은 송영권이 없어 대전 5개구 전역이 영업 범위입니다. 센터 소재(서구 탄방동)를 중심으로 접근성 순서입니다.

서구 본거지
센터 소재구(탄방동). 케어링 둔산·서구 주보와 같은 생활권 — 상호연계 1순위
중구 인접
원도심 고령층 밀집. 대전 방문요양 다수 소재
유성구 인접

대덕구 광역

전략 순서
서구·중구·유성 우선 밀집 확보 → 동·대덕 확장 의견
방문요양의 실질 제약은 행정구역이 아니라 요양보호사의 이동 동선입니다. 초기엔 서구·중구 중심으로 케이스를 밀집시켜 이동 낭비를 줄이고, 요양보호사 확보에 맞춰 유성·동·대덕으로 넓히는 것을 권합니다. 의견

수급자 확보 경로 (B2B 연계망)

방문요양 수급자는 가정에 흩어져 있어 유입 채널이 전부입니다. 대전에서 케어링이 쓸 수 있는 경로입니다.

🏥 병원 퇴원 연계
요양병원·재활·종합병원 퇴원 시 재가 전환. 원무·사회사업실과 협약
→ 퇴원환자 = 즉시 등급 보유 수급자
🔄 케어링 주보 ↔ 방문 상호의뢰
둔산점·서구점 주간보호 이용자 중 방문요양 병행 필요 케이스, 반대로 방문 중 주보 필요 케이스
→ 자사 지점이 곧 파이프라인
🏛 치매안심센터·행정
구별 치매안심센터·주민센터 맞춤돌봄 → 등급자 재가서비스 안내
→ 등급 신규자 유입
🤝 복지관·재가 네트워크
종합사회복지관 사례관리, 방문목욕 필요 케이스 상호 송객
→ 목욕 묶음으로 차별화
유입 흐름: 병원 퇴원/치매안심센터 등급판정 → 초기상담·계약 → 요양보호사 매칭 → 방문 개시 → (필요시) 방문목욕·주보 연계
초기 90일 우선순위. ① 케어링 둔산·서구 주보 지점 명단부터 방문요양 병행 대상 발굴(가장 빠름) ② 서구·중구 요양병원 3~5곳 퇴원연계 협약 ③ 서구 치매안심센터 등록. 전략
